# Hướng dẫn khi mở trực tiếp thư mục firmware

Đọc và áp dụng toàn bộ [`../AGENTS.md`](../AGENTS.md) trước khi làm việc. Nếu phiên khởi động trực tiếp trong thư mục firmware, mở file đó thủ công nếu cần. Đọc [`../docs/03-ngu-canh.md`](../docs/03-ngu-canh.md) khi bắt đầu, cập nhật ngay khi có thay đổi quan trọng và cập nhật mục **Bàn giao phiên gần nhất** trước khi kết thúc.
